# ⚡ Market Flash

Market Flash es una plataforma diseñada para conectar personas que desean comprar y vender de manera sencilla, rápida y organizada.

## 🚀 Proyecto

Este proyecto se está construyendo paso a paso, comenzando desde el sistema de registro e inicio de sesión.

## 👤 Registro de usuarios

El registro contempla:

- Nombre
- Apellido
- Apodo
- Número de cédula
- Dirección
- Número de teléfono (opcional)
- Correo electrónico (opcional)
- Contraseña
- Confirmación de contraseña

El número de cédula será el identificador principal del usuario.

## 🔐 Inicio de sesión

Los usuarios podrán iniciar sesión utilizando:

- Número de cédula
- Contraseña

## 📱 Compatibilidad

La interfaz estará adaptada para:

- Android
- iPhone
- Tablets
- Windows
- Mac
- Laptops
