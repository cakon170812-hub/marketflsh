# ⚡ MIRKET FLASH 

## La energía de comprar y vender

Michael Flash es una plataforma digital moderna diseñada para facilitar la compra y venta de productos de manera rápida, organizada y segura.

---

## 🚀 Primera etapa

La primera etapa del proyecto contiene:

- Pantalla de bienvenida
- Logo Michael Flash ⚡
- Botón Crear cuenta
- Botón Iniciar sesión
- Registro de usuarios
- Inicio de sesión mediante número de cédula y contraseña
- Diseño adaptable para teléfonos, tablets y ordenadores

---

## 👤 Registro

Para crear una cuenta se solicitarán:

- Nombre
- Apellido
- Apodo
- Número de cédula
- Dirección
- Número de teléfono (opcional)
- Correo electrónico (opcional)
- Contraseña
- Confirmación de contraseña
- Aceptación de términos y condiciones

### Identificación principal

El número de cédula será obligatorio para crear una cuenta.

Sin número de cédula no se podrá completar el registro.

---

## 🔐 Inicio de sesión

El acceso se realizará utilizando:

- Número de cédula
- Contraseña

El correo electrónico y el teléfono no serán necesarios para iniciar sesión.

---

## 🎨 Diseño

Michael Flash tendrá una identidad visual:

- Digital
- Futurista
- Moderna
- Adaptable
- Interactiva
- Con efectos de iluminación
- Con animaciones de energía
- Con el rayo ⚡ como elemento principal

Los botones principales tendrán identidad visual propia y efectos luminosos.
