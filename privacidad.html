Política de privacidad

Dominó Flash Coin

Revisión 0.12Z.30 — 4 de noviembre de 2026

1. Responsable y alcance

Esta política describe el tratamiento de datos personales en Dominó Flash Coin, una plataforma que ofrece juegos de dominó, funciones sociales y otras modalidades que se encuentren habilitadas en el servicio.

El responsable es Julio Alcántara, en República Dominicana. Para consultas sobre privacidad: julioangel170812@gmail.com .

Las funciones descritas se aplican cuando estén disponibles en la versión utilizada.

2. Datos personales y finalidades

  • Cuenta y perfil: nombre, correo electrónico, teléfono cuando corresponda, identificador de usuario e información del perfil. Se utilizan para gestionar la cuenta y prestar soporte.
  • Autenticación: información necesaria para iniciar sesión, gestionada mediante Supabase Auth. No debes compartir tu contraseña.
  • Actividad de juego: mesas, participantes, rondas, jugadas, resultados y estadísticas para desarrollar partidas y resolver incidencias.
  • Flash Coin y diamantes: saldos, asignaciones, movimientos internos, recompensas y referencias de operaciones para registrar cambios y prevenir duplicados.
  • Recargas y retiradas: cuando estas operaciones estén habilitadas, se pueden tratar los importes, referencias, estados de solicitudes y datos necesarios para gestionar y verificar cada operación.
  • Datos de pago: cuando el usuario solicite una retirada, puede facilitar los datos bancarios necesarios al canal autorizado que tramite la solicitud. Se utilizarán para gestionar esa operación y atender las incidencias relacionadas.
  • Invitaciones: identificadores de usuarios y eventos de recomendación cuando el programa de recompensas esté habilitado.
  • Comunicaciones: mensajes, solicitudes, denuncias y documentos o evidencias aportados voluntariamente para gestionar soporte y moderación.
  • Datos técnicos: dirección IP, información del navegador, dispositivo y registros de conexión o errores necesarios para seguridad y diagnóstico.

No envíes contraseñas, datos bancarios ni documentos personales en chats públicos. Utiliza únicamente los canales autorizados cuando una operación requiera esos datos.

3. Flash Coin, recargas y retiradas

Flash Coin es la unidad de saldo utilizada dentro de Dominó Flash Coin para las funciones y modalidades habilitadas.

En la versión actual pueden existir asignaciones promocionales, recargas y solicitudes de retirada que involucren dinero real.

Cuando se utilicen esos servicios, podrán intervenir promotores o canales autorizados para recibir solicitudes, comprobar operaciones y tramitar los pagos correspondientes.

Los registros de estas operaciones podrán incluir identificadores de usuario, importe solicitado, saldo, fecha, referencia, estado y los datos necesarios para gestionar el pago.

Las condiciones, importes, límites, disponibilidad y requisitos de cada operación deberán comunicarse al usuario antes de realizarla.

Esta política de privacidad no sustituye los términos económicos, las reglas del juego ni las obligaciones legales aplicables a las operaciones con dinero real.

4. Información visible para otros usuarios

Las funciones sociales y de juego pueden mostrar nombre de perfil, identificador público, avatar, presencia, participación, resultados y saldos de mesa cuando esa visualización forme parte del juego.

Las contraseñas, credenciales de sesión y datos bancarios no están destinados a mostrarse públicamente.

Los mensajes de chat pueden ser visibles para los participantes correspondientes. El personal autorizado podrá revisar los datos necesarios para moderación, soporte y resolución de incidencias.

5. Proveedores y comunicación de datos

Para operar el servicio se utilizan los siguientes proveedores tecnológicos:

  • Supabase: autenticación, base de datos, sincronización y almacenamiento cuando corresponda. Política de privacidad de Supabase .
  • GitHub Pages: alojamiento del sitio web, documentos públicos y archivos de actualización. Política de privacidad de GitHub .
  • WhatsApp: cuando se utilicen enlaces de contacto, los datos compartidos en esa conversación estarán sujetos también a las condiciones de dicho servicio. Política de privacidad de WhatsApp .

Cuando una recarga o retirada sea gestionada mediante un promotor o intermediario autorizado, podrán compartirse los datos estrictamente necesarios para tramitar la solicitud.

Los proveedores o intermediarios de pago que se utilicen deberán informar sobre sus propias condiciones de tratamiento cuando corresponda.

No se venden datos personales con fines publicitarios.

Los proveedores pueden tratar información en otros países según su infraestructura y las condiciones aplicables.

6. Almacenamiento local y sesiones

La aplicación puede utilizar almacenamiento local para conservar sesiones, preferencias y archivos necesarios para su funcionamiento.

El cierre de sesión o la desinstalación no eliminan automáticamente los datos almacenados en los servidores.

7. Permisos del dispositivo

La aplicación requiere conexión a internet para acceder a los servicios en línea.

Las funciones opcionales que necesiten archivos, cámara, micrófono o notificaciones podrán solicitar permisos cuando estén habilitadas y sea necesario.

Los permisos pueden administrarse desde los ajustes del dispositivo.

8. Seguridad

Las conexiones con el sitio y los servicios de autenticación y base de datos utilizan HTTPS para proteger la información durante su transmisión.

El acceso a los datos debe limitarse a usuarios y personal autorizado según las funciones correspondientes.

Ningún sistema ofrece seguridad absoluta. No compartas contraseñas ni credenciales y comunica cualquier acceso sospechoso.

9. Conservación de datos

Los datos se conservan durante el periodo necesario para proporcionar el servicio, atender solicitudes, mantener la seguridad y cumplir las obligaciones aplicables.

Los registros relacionados con recargas, retiradas u operaciones económicas pueden requerir periodos de conservación adicionales por motivos legales, contables o de prevención de operaciones fraudulentas.

Las solicitudes de eliminación se revisarán atendiendo a los derechos del usuario y a las obligaciones de conservación que sean aplicables.

Los datos de copias de seguridad pueden mantenerse hasta que concluya el ciclo de eliminación correspondiente.

10. Solicitar la eliminación de tu cuenta

Puedes solicitar la eliminación de tu cuenta y de los datos asociados escribiendo al siguiente correo:

Solicitar eliminación de cuenta
  1. Envía la solicitud desde el correo asociado a tu cuenta, si tienes acceso.
  2. Indica tu identificador de usuario cuando lo conozcas.
  3. No envíes tu contraseña.
  4. Se verificará la titularidad mediante los datos mínimos necesarios.
  5. Una vez verificada la solicitud, se gestionará la eliminación de los datos que corresponda borrar.
  6. Si existen registros que deban conservarse por obligaciones legales, se informará al usuario cuando corresponda.

Antes de solicitar la eliminación, el usuario deberá revisar cualquier operación económica pendiente. La eliminación de la cuenta no extingue automáticamente obligaciones legales o económicas que correspondan.

Cerrar sesión, bloquear una cuenta o desinstalar la aplicación no equivale a eliminarla.

11. Derechos del usuario

Puedes solicitar acceso, corrección o eliminación de tus datos y ejercer otros derechos reconocidos por la normativa aplicable.

Para evitar el acceso indebido a información de otras personas, se podrá verificar la identidad del solicitante.

Las solicitudes se tramitarán conforme a los plazos y requisitos correspondientes.

12. Menores de edad

Dominó Flash Coin está destinada a personas mayores de 18 años. No está dirigida a niños.

Si un padre, madre o tutor considera que un menor ha proporcionado información personal, podrá solicitar su revisión mediante el correo de contacto.

13. Actualizaciones web y Android

La versión web puede recibir archivos nuevos al volver a cargar el sitio.

En instalaciones Android que utilicen el sistema de actualización correspondiente, la aplicación puede consultar un manifiesto público para detectar versiones disponibles.

Cuando el usuario pulse el botón de actualizar, la aplicación puede descargar archivos de interfaz y comprobar su integridad mediante una suma SHA-256 antes de activarlos.

Se procura impedir que una actualización interrumpa una partida activa.

Las aplicaciones distribuidas mediante tiendas oficiales pueden utilizar los mecanismos de actualización exigidos por la tienda correspondiente.

Esta política se revisará cuando cambien las funciones o el tratamiento de datos.
